# 🔬 โครงการทดลองพัฒนาระบบ (Intelligence Unit)

โปรเจกต์นี้เป็นส่วนหนึ่งของระบบ/เครื่องมือสาธิต (Prototype) ที่พัฒนาขึ้นภายใต้ **การทดลองดำเนินงานของหน่วยข่าวกรองเชิงยุทธศาสตร์ (Intelligence Unit) สำนักงานคณะกรรมการสุขภาพแห่งชาติ (สช.) ภาคเหนือ** 

มีวัตถุประสงค์เพื่อทดลองนำเทคโนโลยีและการประมวลผลข้อมูลมาประยุกต์ใช้ในการขับเคลื่อนงานนโยบายสาธารณะและหนุนเสริมกลไกสุขภาพในระดับพื้นที่ภาคเหนือ

## 📂 รายละเอียดไฟล์ในคลังข้อมูล (Repository)
คลังข้อมูลนี้ใช้สำหรับจัดเก็บไฟล์ต้นแบบ (Static HTML Page) ที่ได้จากการประมวลผลและการออกแบบร่วมกับระบบปัญญาประดิษฐ์ (AI-Assisted Development) เพื่อความสะดวกในการทดสอบระบบและการนำเสนอผลงาน:

## 🛠️ เทคโนโลยีที่ใช้ทดลอง
*   **Core:** HTML5 / CSS3 / JavaScript (Single File Application)
*   **AI Framework:** พัฒนาและเจนเนอเรตโครงสร้างโค้ดร่วมกับ Claude AI
*   **Deployment:** โฮสต์และแสดงผลผ่าน [ระบุแพลตฟอร์มที่ใช้ เช่น GitHub Pages / Vercel]

---
**หมายเหตุ:** ไฟล์ทั้งหมดใน Repository นี้เป็นตัวต้นแบบเพื่อการทดลองภายใน (Experimental Purpose) ของ สช. ภาคเหนือ เท่านั้น ยังไม่ใช่ระบบที่เปิดใช้งานอย่างเป็นทางการเต็มรูปแบบ
